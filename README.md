# wando-fabber-carrd

A lightweight, high-performance static resource and project hub built using the **Carrd** editor. Designed for speed, clarity, and zero-maintenance deployment, serving as a centralized directory for updates, reference guides, and bookmarks.

---

## Project Overview

| Property | Details |
| --- | --- |
| **Project Name** | Wando Fabber |
| **Platform** | Carrd (Static Site Builder) |
| **Domain** | `wandofabber.carrd.co` |
| **Primary Purpose** | Centralized project reference, bookmark repository, and clean update feed |

---

## Skills & Technologies Used

* **Visual & Content Design (`Carrd Editor`)**: Rapid layout composition, responsive section ordering, and minimalist user interface design tailored for fast mobile and desktop loading.
* **Front-End Styling (`CSS / Custom Embeds`)**: Typography tuning, color palette hierarchy, and responsive spacing adjustments injected via Carrd's custom code block.
* **Version Control (`Git & GitHub`)**: Asset storage, README documentation, and change tracking for project metadata.
* **Performance Optimization**: Image compression, asset minimization, and clean DOM rendering ensuring near-instant load times.
